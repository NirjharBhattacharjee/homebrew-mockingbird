# homebrew-mockingbird

Homebrew tap for [mockingbird](https://github.com/NirjharBhattacharjee/mockingbird),
local voice dictation for macOS.

```sh
brew install nirjharbhattacharjee/mockingbird/mockingbird
mockingbird models pull
mockingbird start
```

Update with `brew upgrade mockingbird`, then `mockingbird restart`.

The formula is bumped by a pull request that mockingbird's release workflow
opens for each tagged release.
